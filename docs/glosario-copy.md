# Glosario de copy — GymFlow

Variante única de español para TODO el copy de GymFlow (frontend y backend):
**español neutro con tuteo (Colombia)**. Aprobado por auditoría M-04
(2026-08-13): se eliminó la mezcla voseo/tuteo.

## Formas PROHIBIDAS (voseo) y su reemplazo

| Prohibido (voseo) | Correcto (tuteo) |
|---|---|
| tenés | tienes |
| podés | puedes |
| querés | quieres |
| necesitás | necesitas |
| sabés | sabes |
| Creá | Crea |
| Elegí | Elige |
| Agregá | Agrega |
| Completá | Completa |
| Presentanos | Preséntanos |
| asignalas | asígnalas |
| acompañame | acompáñame |
| ayudame | ayúdame |

Cualquier otra forma de voseo (verbos conjugados en 2ª persona plural
voseante, imperativos voseantes como *mirá*, *contá*, *dejá*, *mostrá*) está
prohibida: usar la forma de tuteo correspondiente.

## Elipsis

Usar SIEMPRE el carácter `…` (U+2026). Nunca `...` (tres puntos ASCII) en
copy de UI ni en mensajes de error.

## Tono

Imperativo amistoso de tuteo en estados vacíos, toasts y acciones de botón.
Ejemplos: "Elige un cliente", "Crea rutinas", "Agrega al menos un ejercicio",
"Todavía no tienes un entrenador asignado".
